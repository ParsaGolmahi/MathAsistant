## 📌 About IMA

**IMA (Intelligent Mathematics Assistant)** is an educational mathematics platform designed to make learning mathematics more interactive, intelligent and accessible.

IMA combines mathematics, programming and technology to provide students and teachers with powerful tools for solving problems, understanding concepts and managing learning processes.

This project was created with the goal of building a modern mathematical environment where students can explore mathematics beyond traditional methods.

## ✨ Features

### 🧮 Mathematical Tools

- 🔢 Prime number detection
- 📐 Greatest Common Divisor (GCD)
- 📊 Least Common Multiple (LCM)
- 🧩 Egyptian Fraction conversion
